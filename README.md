# 雙人羽毛球 Badminton 2P

俯視視角、同機對戰的網頁羽毛球小遊戲。純前端，單一 `index.html`，瀏覽器打開即玩。

## 玩法

- 落地得分制，先到 21 分且領先 2 分獲勝。
- 球靠近你時按擊球鍵。擊球瞬間：
  - **往前壓（靠近網）** → 快速殺球
  - **站定** → 標準回擊
  - **後退** → 高遠球
  - **左右移動** → 控制落點

| | 玩家 1（綠・下半場）| 玩家 2（紅・上半場）|
|---|---|---|
| 移動 | `W` `A` `S` `D` | `方向鍵` |
| 擊球 | `空白鍵` | `Enter` |

`M` 鍵切換音效。

## 特色

音效、球的殘影軌跡、擊球火花、螢幕震動、球種浮動文字、連拍 Combo 與最佳連拍紀錄、賽末點提示、發球指示箭頭。

## 部署

純靜態網站，部署於 Cloudflare Pages（連動本 GitHub repo，push 後自動部署）。
